# Baton · 本周必交 / 可顺延 Checklist

> 写于 2026-10-31（Asia/Shanghai）｜嵌做梦梦作息：**约 22:00 睡、6:00 起**；晚饭后散步、晨晚量血压优先于发帖。
> 文案基调：冷静、不吓人——额度提示用「快到线了，交接单已备好」，不用「额度告急」。

---

## 原则（每天过一眼）

1. **一天只打一个主战场**（深度编码 / 发帖 / 守评三选一当「主」，其它最多轻扫）。
2. **平常日 21:30 前收工**，22:00 上床；只有 **Show HN 当晚** 允许破例晚场。
3. **守评 = 闹钟 + 短模板**，不是通宵盯屏。
4. 晨测低压连续偏高或明显疲乏 → **当周砍掉晚场**，只留白天事项。

---

## A. 本周必交（演示闭环）

目标：别人能 `npx` 试到「撞线感 → 交接单 → 一条命令接着干」，并有一份诚实 README + 30 秒演示。

| # | 事项 | 建议时段（嵌作息） | 完成标准 | ☐ |
|---|---|---|---|---|
| A1 | 查重定名（npm / GitHub / 域名），建仓库 MIT | **白天**（6:30 后或午睡后）；勿熬夜纠结命名 | 仓库可访问；包名可用或已定备选名 | ☐ |
| A2 | `baton init` / `status` / `remove`（含配置备份） | **上午～傍晚深度工作块**；晚饭散步前收尾 | 本机能装、能卸干净；`doctor` 或等价自检有说明 | ☐ |
| A3 | 85% 触发写 `HANDOFF.md`（Stop / 撞线补写） | 同上深度块；文案冷静：「快到线了，交接单已备好」 | 真实项目里能自动/半自动产出可读交接单 | ☐ |
| A4 | `baton go codex\|claude\|cursor` | 同上 | 目标 CLI 能带着交接上下文启动（Cursor 可先剪贴板） | ☐ |
| A5 | 自己项目来回接力 ≥3 次，记下失败点 | **白天**；失败点写进 `DECISIONS.md` 或 FAQ 草稿 | 有 3 次记录 + 已知坑列表 | ☐ |
| A6 | 录 **30 秒 GIF**（可另备 60 秒视频） | **傍晚光线好时**，21:00 前导出完毕 | README / 发帖能直接嵌；首屏看懂「接着干」 | ☐ |
| A7 | README：一句话定位 + 不做什么 + 隐私/非官方 + 竞品诚实对比 | **晚饭后散步之后、21:30 前** 写一版可发 | 含「不提高额度、不轮换账号」；链接开源与试用 | ☐ |

**本周必交的「不做」**：不要求本周内付费闭环、双语落地页、多平台群发、爱发电/Lemon 全打通——那些进 B 区。

## D. Show HN 当晚（唯一破例晚场）

前提：A1–A7 已勾完；草稿与 FAQ 短句 **当天下午前写好**。

| 时间 | 做什么 |
|---|---|
| 当天 ≤21:00 | 定稿标题/正文；导出 GIF；列好开场回复与「局限」标准答 |
| 20:00 | 照常量血压；可小憩 20 分钟 |
| **23:00–23:45** | 第 1 轮守评（认真回） |
| 23:45–00:30 | **离开屏幕**休息 |
| **00:30–01:00** | 第 2 轮守评 |
| 01:00 后 | 只留「真有关键再响」的闹钟；不硬撑通宵 |
| 次日晨 | 允许晚起 30–60 分钟；拉伸与血压保留；散步可减量；**上午再扫一轮评论** |

饮料：温水/无糖；不靠咖啡续到凌晨。

## E. 红线（写进协作约定）

- 连续两晚超过 **00:30** 仍在屏幕前 → 次日砍掉非必要发帖，只保睡眠与血压。
- 晨测高压 ≥140 或低压 ≥90 需留意；若连续偏高或人明显疲乏 → **暂停晚场**，获客改白天。
- 发帖日不取消晚饭后散步；用发帖顶掉运动 = 本周节奏失败。
